# 动态验证码屏幕保护 Android App

极简版本：全屏屏幕保护界面 + Google Authenticator 兼容的 TOTP 验证码解锁。旧版的使用统计、游戏选择、护眼计时等功能已移除。

## 功能
- 全屏深色屏幕保护界面，无应用内退出按钮
- 首次启动生成 20 字节随机密钥，并加密保存在本机；家长在 Google Authenticator 中手动添加 TOTP 密钥
- 使用 6 位、30 秒周期、HMAC-SHA1 的 RFC 6238 TOTP 验证
- 验证通过后进入 40 分钟倒计时，倒计时结束返回保护界面
- 锁定时拦截应用内返回键
- 开机广播尝试重新打开应用
- GitHub Actions 自动运行 TOTP 单元测试并构建 Debug APK

## 首次设置
1. 安装并打开 APK。
2. 首次启动时将屏幕显示的密钥添加到家长自己的 Google Authenticator，类型选“基于时间”。
3. 确认已添加。后续输入验证器中的当前 6 位动态验证码解锁。

请保管好密钥。当前版本没有远程恢复密钥流程；如果密钥丢失，需要设计安全的重置/重新绑定流程。

## 重要限制
这是普通 APK 原型，不是系统级锁屏。Android/荣耀系统可能阻止开机广播自动启动；Home、最近任务、系统设置、强行停止和卸载仍可能绕过应用。当前 40 分钟计时只在本应用进程/界面存活时有效，并不代表解锁后手机所有应用都能被可靠计时后重新锁住。

如果需求是“解锁后正常使用整部手机 40 分钟，时间到后无论正在使用哪个应用都必须重新输入验证码”，必须进一步开发并配置 Device Owner / Lock Task 的设备管理版本，或使用具备系统权限的设备管理方案。该方案可能要求在设备初始设置阶段配置；执行前请备份数据，并先在备用设备测试。普通 APK 不能保证拦截系统导航键。

## 构建
GitHub Actions 使用 JDK 17，执行 `gradle testDebugUnitTest assembleDebug`。
构建成功后，在 **Actions → Android APK → 对应运行记录 → Artifacts** 下载 `ChildCareAndroid-debug`，解压后安装 `app-debug.apk`。
